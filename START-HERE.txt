ATELIER CHESS — INDEPENDENT DEPLOYMENT

This folder is a complete static website. Keep all files together.

QUICK START: NETLIFY
1. Extract this ZIP into a folder on your computer.
2. Create or log in to your own Netlify account.
3. Visit https://app.netlify.com/drop
4. Drag the extracted folder containing index.html onto the upload area.
5. Open the resulting netlify.app address. Check the project's visibility;
   if Netlify marks it private, change it to public when you want visitors.
6. Optionally connect your own domain through Netlify's domain settings,
   following the DNS records supplied there.

UPDATES
Open this same project's dashboard and upload the complete updated folder
under Production deploys. This updates the existing site.

BUILD SETTINGS (only if another host asks)
Framework: None / Static HTML
Build command: None (leave empty)
Publish directory: The folder containing index.html
No API keys, package installation or ChatGPT hosting are required.

NOTES
Prices and product imagery are illustrative. Payments and order submission
are not connected. Saved designs stay in the visitor's browser and do not
transfer between different domains. Fonts load from Google Fonts, with local
font fallbacks if unavailable.

Official Netlify guide:
https://docs.netlify.com/start/quickstarts/netlify-drop-quickstart/
